# Odin Mapa — Integración de Mapas en Android

![Kotlin](https://img.shields.io/badge/Kotlin-7F52FF?style=flat&logo=kotlin&logoColor=white)
![Android](https://img.shields.io/badge/Android-3DDC84?style=flat&logo=android&logoColor=white)
![Google Maps](https://img.shields.io/badge/Google%20Maps-4285F4?style=flat&logo=googlemaps&logoColor=white)

Aplicación Android desarrollada en Kotlin enfocada en la integración de mapas,
geolocalización y manejo de marcadores. Demuestra el trabajo con servicios de
ubicación y la visualización de datos geográficos en una app nativa.

## Características

- Integración de mapas interactivos dentro de la app
- Obtención y visualización de la ubicación del usuario
- Colocación y gestión de marcadores sobre el mapa
- Manejo de permisos de ubicación en tiempo de ejecución

## Stack tecnológico

| Herramienta      | Uso                          |
| ---------------- | ---------------------------- |
| Kotlin           | Lenguaje principal           |
| Google Maps SDK  | Renderizado e interacción de mapas |
| Android SDK      | Framework de desarrollo      |
| Android Studio   | Entorno de desarrollo (IDE)  |
| Gradle           | Gestión de dependencias      |

## Requisitos

- Android Studio (versión reciente)
- JDK 11 o superior
- Una API key de Google Maps
- Un emulador o dispositivo físico con Android

## Instalación y ejecución

```bash
git clone https://github.com/PocheDevv/odin-mapa.git
```

1. Abre el proyecto en Android Studio.
2. Espera a que Gradle sincronice las dependencias.
3. Añade tu API key de Google Maps en el archivo de configuración
   (`local.properties` o `AndroidManifest.xml`, según corresponda).
4. Ejecuta la app en un emulador o dispositivo físico.

## Estado del proyecto

Proyecto funcional, usado como referencia para la integración de mapas y
servicios de geolocalización en Android.
