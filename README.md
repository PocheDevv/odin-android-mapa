# odin-mapa

Proyecto de referencia de Android en Kotlin enfocado en la integración de mapas.
Practica el uso de la API de mapas, la ubicación del usuario y la colocación de
marcadores sobre el mapa.

## Tecnologías
- Kotlin
- Android Studio
- Google Maps SDK

## Cómo ejecutarlo
1. Clona el repositorio.
2. Ábrelo en Android Studio.
3. Deja que Gradle sincronice las dependencias.
4. Configura tu API key de Google Maps en el archivo correspondiente.
5. Corre la app en un emulador o dispositivo físico.
